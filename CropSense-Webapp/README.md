# CropSense Webapp

Mobile-first Next.js scaffold for CropSense, inspired by the Streamlit TensorFlow prototype and the iOS-style CropMate visual references.

## Run

```bash
npm install
npm run dev
```

## Current Scope

- Three-tab app shell: Home, Scan, Care.
- Camera/file picker UI using browser capture and image upload support.
- Mock diagnosis output shaped after the Python app classes and treatment advice.
- Local crop assets from the existing CropSense MAUI project plus Lucide icons.
