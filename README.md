# CropSense



Abstract

Title: A Deep Learning Web Application for Real-Time Crop Pest and Disease Detection in Ghana Using ResNet50Background: Crop pests and disease infestations pose severe threats to food security and agricultural productivity in developing nations like Ghana. 
Smallholder farmers often face critical challenges, including a lack of expert agricultural extension services and a technical knowledge gap in diagnosing plant pathologies early.

Objective: This study develops a web-based deployment application that leverages deep learning to provide farmers with instant, localized crop diagnostic tools and actionable treatment solutions.Methodology: A ResNet50 deep learning architecture was trained and evaluated using a comprehensive local Ghanaian dataset (Mendeley Data, DOI: 10.17632/bwh3zbpkpv.1). 

The dataset contains 102,976 augmented images categorized into 22 distinct classes across four vital regional crops: Cashew, Cassava, Maize, and Tomato. All data points were validated by expert plant virologists. The trained model was integrated into a responsive web application featuring real-time camera capture capabilities for immediate on-field analysis.

Results: The ResNet50 model achieved a high training accuracy of 96% across all 22 image classes, demonstrating robust feature extraction capabilities for diverse local crop diseases. Upon deployment, the web application successfully performs instant visual analysis of uploaded or captured plant images, immediately returning accurate diagnostic results alongside localized prevention and cure procedures.

Conclusion & Signification: This project aligns directly with the TVET framework by transferring advanced AI research into an accessible, practical tool for the agricultural sector. By bridging the gap between smallholder farmers and expert tech-driven diagnostics, the application provides a scalable solution to improve crop yields, optimize pesticide use, and support sustainable agricultural development in Ghana.Keywords: Deep Learning, ResNet50, Crop Disease Detection, TVET Innovation, Smart Agriculture, Ghana.
